# tesla-player

## Project setup

```bash
npm install
```

### Compiles and hot-reloads for development

```bash
npm run serve
```

#### To expose it to the network

```bash
npm run serve:host
```

You also need to modify the `.env` file with :

```.env
VITE_BASE_URL=http://{LOCAL_IP}:5000
```

### Compiles and minifies for production

```bash
npm run build
```

### Lints and fixes files

```bash
npm run lint
```
